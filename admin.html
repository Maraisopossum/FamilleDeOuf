🛠️ Admin — Questions du Quiz

Outil pour éditer, ajouter, importer en masse et supprimer des questions/catégories, sans jamais retoucher le JSON à la main. Cette page n'est pas reliée au jeu — garde son URL pour toi.

1. Connexion au dépôt GitHub

Renseigné une fois, c'est sauvegardé sur cet appareil. Le token n'est envoyé qu'à GitHub, jamais ailleurs.

Comment créer un token GitHub ?

1. Va sur github.com/settings/tokens?type=beta
2. « Generate new token » (fine-grained)
3. Limite-le à ce seul dépôt, permission Contents: Read and write
4. Copie le token généré et colle-le ci-dessus (il ne sera montré qu'une seule fois par GitHub)
